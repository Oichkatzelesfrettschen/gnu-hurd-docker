# Reports (Non-Canonical)

Files in `docs/reports/` are point-in-time “report” artifacts (often generated during audits or tool-assisted refactors). They may contain:

- Historical assumptions (including i386-era details)
- Legacy service/container names
- Stale upstream image build IDs and URLs

Use these as background context only. For current behavior and supported workflows, prefer:

- `docs/index.md`
- `gemini.md`
- `README.md`
- The canonical guides under `docs/01-GETTING-STARTED/`, `docs/02-ARCHITECTURE/`, `docs/03-CONFIGURATION/`, `docs/04-OPERATION/`, `docs/05-CI-CD/`, and `docs/06-TROUBLESHOOTING/`
